# Orion multi-user paper workspace

The Expo app provides isolated accounts, pending owner approval, Telegram channel selection, Kotak Neo connection, virtual cash and risk settings. The owner can approve/suspend users and review their paper performance and paginated signal activity. Live mode is disabled by the API.

One Telegram identity and one Kotak connection are supported per Orion user, with up to 20 selected channels and explicit index/commodity instrument profiles. Dhan remains planned.

Workers run on the server and are automatically supervised. See [mobile deployment and testing](mobile-testing.md) for the complete setup and release gates. Public distribution, account deletion/recovery and signed phone installation remain separate release work.
